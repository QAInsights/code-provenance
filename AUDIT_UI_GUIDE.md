# AI Code Audit UI - User Guide

## Overview

The AI Code Audit UI provides a comprehensive dashboard for tracking, analyzing, and auditing AI-generated code in your project. All data is stored **per-project** in `.vscode/provenance/audit-trail.json`.

## Features

### 📊 Real-Time Statistics Dashboard
- **Total AI Generations**: Count of all detected AI code
- **Average Confidence**: Mean confidence score across all detections
- **Tab Completions**: Number of tab-completion events
- **Block Completions**: Number of multi-line block completions

### 🔍 Advanced Filtering
- **Risk Level Filter**: Filter by low, medium, high, or critical risk
- **Language Filter**: Filter by programming language
- **Search**: Search by file name

### 📝 Detailed Audit Records
Each record shows:
- **File path** and **line range**
- **Language** and **timestamp**
- **Detection speed** (milliseconds)
- **Confidence score** (percentage)
- **Risk level** with color coding:
  - 🟢 Green: Low risk
  - 🟠 Orange: Medium risk
  - 🔴 Red: High risk
  - 🟣 Purple: Critical risk
- **Compliance flags**: HIPAA, GDPR, PCI-DSS, SOX
- **Detection type badges**: Tab completion, Block completion

### 🎯 Quick Actions
- **Open File**: Jump directly to the AI-generated code
- **Delete Record**: Remove individual audit entries
- **Export**: Export full audit trail as JSON
- **Clear All**: Remove all audit records (with confirmation)

## Commands

Access these commands via Command Palette (Ctrl+Shift+P / Cmd+Shift+P):

1. **Code Provenance: Show Audit Trail**
   - Opens the main audit dashboard
   - Keyboard shortcut: Can be customized

2. **Code Provenance: Show Status**
   - Quick status notification with key metrics

3. **Code Provenance: Query Current File**
   - Shows AI-generated code in the active file

4. **Code Provenance: Validate Repository**
   - Checks for high-risk AI code requiring review

5. **Code Provenance: Export Audit Trail**
   - Export audit data to JSON file

## How It Works

### Detection System

The extension uses multiple heuristics to detect AI-generated code:

1. **Tab Completion Detection** (30% confidence)
   - Very fast insertions (< 100ms)
   - Small to medium snippets (< 80 chars)
   - Complete tokens

2. **Block Completion Detection** (35% confidence)
   - Multi-line insertions (> 3 lines)
   - Large code blocks (> 50 chars)

3. **Speed + Size Heuristic** (30% confidence)
   - Fast insertions (< 1000ms) with large size (> 50 chars)

4. **Structured Code Patterns** (20% confidence)
   - Function declarations
   - Class definitions
   - Export statements

5. **AI Signatures** (5% confidence)
   - Comments like "Made with Bob", "Generated by AI"

### Risk Assessment

Code is automatically assessed for risk level:

- **Critical**: Contains passwords, secrets, API keys
- **High**: Authentication, login, payment, encryption
- **Medium**: Database queries, SQL, API calls
- **Low**: General code

### Compliance Detection

Automatically flags code that may require compliance review:

- **HIPAA**: Medical, health, patient data
- **PCI-DSS**: Payment, credit card, billing
- **GDPR**: Personal data, privacy, consent
- **SOX**: Financial, audit data

## Storage

### Per-Project Storage
All audit data is stored in your project at:
```
.vscode/provenance/audit-trail.json
```

### Git Integration
The `.vscode/provenance/` directory is automatically excluded from:
- Git commits (via `.gitignore`)
- Extension packaging (via `.vscodeignore`)

This ensures audit data stays local to each developer's workspace.

## Best Practices

### For Developers
1. **Review High-Risk Code**: Always review code flagged as high or critical risk
2. **Check Compliance Flags**: Pay attention to HIPAA, PCI-DSS, GDPR flags
3. **Export Regularly**: Export audit trails before major releases
4. **Monitor Confidence**: Low confidence scores may indicate false positives

### For Compliance Officers
1. **Regular Audits**: Review the audit trail weekly or before releases
2. **Filter by Risk**: Focus on high and critical risk items first
3. **Export for Records**: Keep exported JSON files for compliance documentation
4. **Validate Coverage**: Ensure all AI-generated code is captured

### For Team Leads
1. **Track AI Usage**: Monitor team's AI adoption through statistics
2. **Set Standards**: Define acceptable confidence thresholds
3. **Review Process**: Establish review workflows for flagged code
4. **Training**: Use audit data to identify training needs

## Troubleshooting

### No Records Showing
- Ensure you're in a workspace folder (not just an open file)
- Try generating some AI code to test detection
- Check the Output panel for "Code Provenance" logs

### False Positives
- Adjust detection thresholds in settings (future feature)
- Delete individual false positive records
- Report patterns to improve detection

### Missing Detections
- Very small changes (< 10 chars) are not tracked
- Manual typing is not detected (by design)
- Check if the file type is supported

## Privacy & Security

### What's Tracked
- File paths (relative to workspace)
- Line ranges
- Code hashes (SHA-256)
- Detection metadata
- Timestamps

### What's NOT Tracked
- Actual prompts sent to AI
- User credentials
- API keys or secrets
- Full file contents (only changed code)

### Data Location
- All data stored locally in `.vscode/provenance/`
- No data sent to external servers
- Not included in git commits by default
